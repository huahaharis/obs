## 🚀 Features

- 🧠 **Zustand Store** for lightweight and scalable state management  
- ⚙️ **Vite** for fast development and build performance  
- 🎨 **Ant Design + Tailwind CSS** for an elegant, responsive UI  
- 🔁 **Reusable components** for modals, cards, and forms  
- 📱 **Fully responsive layout** (mobile, tablet, desktop)  
- 🧪 **Unit testing** with Jest (or Vitest alternative)  
- ⚡️ **TypeScript** for type safety and maintainability  

---

## 📁 Folder Structure

```
src/
 ├── components/       # Reusable UI components (UserCard, UserModal, etc.)
 ├── pages/            # Page-level views (UserListPage)
 ├── store/            # Zustand store (useUserStore)
 ├── types/            # TypeScript types
 ├── utils/            # API Handler
 ├── _test_/           # Unit tests
 ├── main.tsx          # Entry point
 └── App.tsx           # Root component
```

## ⚙️ Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/huahaharis/obs
   cd obs
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm run dev

   npm run dev -- --host
   run with local network 
   ```

4. **Open the app**
   ```
   http://localhost:3000

   http://192.168.*.***:3000/
   ```
